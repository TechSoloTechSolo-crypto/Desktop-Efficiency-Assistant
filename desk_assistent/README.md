# 桌面效率助手

> Windows 平台轻量悬浮桌面效率工具 · 软件工程课程大作业

面向在校大学生的 Windows 悬浮效率工具。以一个常驻桌面的悬浮工具条为统一入口，集成剪贴板历史、任务清单、文件检索、课表、消息提醒五大功能模块，覆盖大学生高频桌面操作与校园场景。全部数据本地存储，不上传网络。

## 功能模块

| 模块 | 核心功能 | 约束 |
|---|---|---|
| 剪贴板历史记录 | 后台监听自动保存文本剪贴；列表展示、关键词搜索、一键粘贴；常用文本收藏、过期记录自动清理 | 仅处理文本；本地 SQLite 存储 |
| 任务清单 | 新建、编辑、勾选完成、删除待办；按状态查看；与提醒窗联动，截止时间到点弹窗 | 提醒由本地数据驱动 |
| 文件快速检索 | 对指定目录建立本地文件索引；按后缀、修改时间筛选；一键打开文件或所在文件夹 | 手动刷新索引，不做实时后台索引 |
| 课表 | 周视图管理课程名称、时间、地点，支持单双周；支持教务系统导出的 Excel 一键导入 | 手工录入 + 文件导入，不接教务系统账号 |
| 消息提醒窗 | 定时扫描本地课表与任务数据，到点弹出无边框置顶提醒窗 | 仅本地数据驱动，不联网 |

## 技术栈

- **开发语言**：Python
- **界面框架**：PySide6（LGPL，对外发布优先）
- **数据存储**：SQLite
- **运行平台**：Windows
- **打包方案**：PyInstaller（开发阶段确定）

## 快速开始

```bash
pip install -r requirements.txt
python -m src.main
```

## 分层架构

- **UI 层**：只负责展示与交互，通过 service 层访问数据
- **Service 层**：封装五大模块的业务逻辑与 CRUD
- **Database 层**：SQLite 连接管理、建表、数据模型定义
- **Config / Utils**：全局配置与通用工具（日志等）
